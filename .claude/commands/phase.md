אנחנו עובדים על **שלב $ARGUMENTS** מתוך `PLAN.md`.

1. קרא את שלב $ARGUMENTS ב-`PLAN.md`, את "יומן התקדמות" בסוף הקובץ, ואת הסעיפים הרלוונטיים ב-`spec-real-estate-site.md`.
2. בדוק את הקוד הקיים: מה כבר נבנה בשלבים קודמים ומה אפשר לנצל.
3. אם שלב קודם לא סומן כגמור ביומן, עצור ושאל לפני שממשיכים.
4. הצג תוכנית קצרה: קבצים שייווצרו או ישתנו, ספריות שיותקנו (ולמה), ושאלות פתוחות. **חכה לאישור לפני שכותבים קוד.**
5. בנה, ובדוק תוך כדי. בסוף הרץ `npm run build`, `npm run lint`, `npm run typecheck`, `npm test`, ועבור על רשימת "גמור כש" של השלב. כל סעיף שאפשר לבדוק בעצמך (דפדפן, שאילתות, סקריפטים), בדוק. אל תסמן משהו כעובד אם לא בדקת אותו.
6. סכם: מה נבנה, מה נבדק ואיך, מה המשתמש צריך לבדוק בעצמו, והחלטות שהתקבלו בדרך.
7. עדכן את "יומן התקדמות" ב-`PLAN.md`, והצע commit.
